MernVerse<br>
Mernverse-lms is a Learning Management System designed to make online learning easier for both students and instructors.

🌐 Link : https://lms-xi-pink.vercel.app

📚 About
LMS-XI provides a platform where instructors can create and manage learning content, while students can access educational resources, take quizzes, and track their learning progress.

The platform supports different types of learning materials, including:<br>
🎥 Videos<br>
📄 PDFs and documents<br>
📝 Quizzes<br>
📚 Course content<br>
📊 Student progress tracking<br>

✨ Features<br>

👨‍🏫 For Instructors<br>
Create and manage courses<br>
Upload and share learning materials<br>
Add videos and PDF resources<br>
Create quizzes for students<br>
Monitor student activity<br>
Track student progress and performance<br>

👨‍🎓 For Students<br>
Browse and access course content<br>
Watch educational videos<br>
Read PDFs and other learning materials<br>
Attempt quizzes<br>
Track their learning progress<br>

🎯 Goal
The goal of LMS-XI is to provide a simple and centralized platform where instructors can share educational content and evaluate students, while students can learn, practice, and monitor their progress in one place.
